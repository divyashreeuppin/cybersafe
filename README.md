# 🛡️ CyberSafe

### Cybersecurity Awareness Quiz Website

CyberSafe is a beginner-friendly web application designed to improve cybersecurity awareness through an interactive quiz.

## Features

- 10 cybersecurity questions
- Multiple-choice answers
- Automatic score calculation
- Final quiz result
- Restart quiz option
- Responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Start answering the quiz questions.
